# formation-machine-learning

## Installation générale

```bash
pyenv install 3.12.7
pyenv local 3.12.7  # Définit la version pour le répertoire courant


python -m venv .venv          # Crée l'environnement dans un dossier .venv
source .venv/bin/activate     # Activation (Linux/macOS)
# .venv\Scripts\activate      # Sur Windows
pip install requests numpy    # Installe des packages
deactivate                    # Désactivation

```
