# Linear Regression from Scratch with Adaptive Learning Rate
Predicts house price from surface area (10 samples).
- Batch gradient descent
- Adaptive learning rate (increases if convergence is slow, decreases if too fast)
- Visualization of learning rate and error evolution (log scale)
- Comparison with scikit-learn LinearRegression (identical results)
- Converges to w ≈ 4000 (€/m²), b ≈ 50000 (€)
